- `collect.sh` — copy the machine-side files of the fleet into this project: the resource guard, systemd units, agent lists (banned name swapped for its stand-in, `config/` only), terminal config, the tmux patch, and the fleet's keys from Claude's and Gemini's settings. The fleet's own programs and tmux config already live here (home paths are links), so they are counted as "already live", not copied. Never copies sign-ins or chats. `bash _tools/collect.sh [--dry-run]`. Exits non-zero if a listed file is missing.
- `install.sh` — set a machine up to run the fleet from this folder: links the home paths of the programs, library, tmux config and launcher files to the files here, and copies the guard, units and lists as real files. Dry run by default; `--apply` does it and keeps anything it replaces as `<file>.bak-<date>`; `--apply --copy` makes real copies instead of links. Does not sign in, edit agent settings, build tmux or restart anything; it prints those steps. `bash _tools/install.sh [--apply] [--copy]`.
- `test-fleet.sh` — try the launcher on a throw-away fleet before trusting it with the real one: its own tmux server, its own home folder under `/tmp`, and stand-ins for the four agents, `notify-send` and the usage tools, so nothing real is started, asked or shown. About 80 checks in three minutes: the saved layout and a restart that gives it all back, a fleet going down hard, notifications, the limit warning, the overview, tab signals, work folders, handing a chat on, `--doctor`. `bash _tools/test-fleet.sh [--bin DIR] [--conf FILE] [--keep]`. Exits 1 if a check fails. Run it after any change to `bin/agents`.
- `build-tmux.sh` — build the fleet's patched tmux 3.8 from this folder alone: `tmux/src/tmux-3.8.tar.gz` + `tmux/afc-tmux-3.8.patch` + the build packages in `tmux/deps/` (checked against `tmux/SHA256SUMS`). No download, no sudo, about a minute. Installs to `~/.local/opt/tmux-3.8` and keeps the previous program as `bin/tmux-before-<date>`. `bash _tools/build-tmux.sh [--prefix DIR] [--dry-run]`. Does not restart the fleet.
